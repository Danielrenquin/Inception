# Inception
A containerization project using Docker, featuring MariaDB, WordPress, and Nginx configured as a reverse proxy.

This project has been crated as a part of the 42 curriculum by Daniel Renquin.
The purpose of this this project was to introduce myself to the contenarisation.

I have learned here the basics of manipulation of container how to load or create my own image
and how i can load this image with a volume.
Them i introduce myself to some configuration with Dockerfile and docker-compose.
